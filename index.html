PROJECT 02

Website Evaluation
Using Opinion Mining

PROJECT OBJECTIVE

With an overwhelming variety of websites available online, users frequently struggle to discern which platform is genuinely trustworthy and superior. This system automates website evaluation by scraping real user reviews and star ratings, running sentiment analysis, and ranking platforms based on transparent, opinion-mined metrics — helping consumers choose better services while giving website owners actionable customer feedback.

ENGINEERING HIGHLIGHTS

  • Web Scraping with BeautifulSoup: Programmatically harvested user reviews, star ratings, and publication timestamps from TrustPilot for premier e-learning platforms including Udemy, Coursera, and edX, organizing datasets into structured Excel repositories.
  • NLTK Preprocessing Pipeline: Engineered comprehensive natural language text cleaning: special character filtering, case folding, stopword removal, word tokenization, and morphological lemmatization to extract pure contextual semantics.
  • Hybrid Sentiment Lexicon Scoring: Implemented a dual-scoring framework combining TextBlob (measuring continuous polarity −1 to +1 and subjectivity) with VADER (specialized in handling punctuation intensity, capitalization, and colloquial terms) to categorize reviews into Positive, Negative, and Neutral.
  • Stacked Ensemble Machine Learning Classifier: Trained a composite ensemble model integrating Multinomial Naive Bayes, Logistic Regression, and Random Forest over TF-IDF feature matrices.
  • SMOTE Class Balancing: Applied Synthetic Minority Over-sampling Technique (SMOTE) to overcome severe sentiment class skew, boosting model classification accuracy to ~70%.
  • Automated Trust & Quality Scoring: Evaluates any target website from real customer feedback, outputting comprehensive benchmark scores that demystify platform quality for end-users.

3 CORE INTERACTIVE DASHBOARDS

  • 01 — Overview Dashboard (Market Snapshot): Displays high-level market health and stock trajectory. Visualizes stock price trends (interactive line charts), trading volume movement (bar charts), sector-wise performance allocation (pie/donut charts), and real-time prices. Features dynamic multi-parameter slicers by ticker and custom date ranges, alongside key financial KPIs: Return on Equity (ROE), Earnings Per Share (EPS), and Price-to-Earnings (P/E) ratios.
  • 02 — Company Profile Dashboard (Fundamental Deep Dive): Showcases company-specific intelligence: enterprise name, sector classification, executive leadership (CEO), corporate headquarters location, branding/logo, business overview, total market capitalization, and competitive positioning within its industry peer group.

Charts multi-period Revenue, Net Profit, and EPS growth trajectories; tracks critical financial health ratios (ROE, P/E, Debt-to-Equity); and computes technical indicators including Moving Averages (SMA/EMA), Relative Strength Index (RSI), and MACD to evaluate financial resilience and optimal trade timing.
